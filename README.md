# Wanderlog

Wanderlog is a responsive travel planning website created for the
CodGen Frontend Internship Week 4 task.

## Features

- Responsive design
- Home page
- Popular destinations
- Add Trip
- Edit Trip
- Delete Trip
- View Trip
- Search Trips
- LocalStorage
- Form validation
- Error handling
- Broken image fallback
- Toast notifications
- Responsive navigation
- Accessibility support
- Profile page
- Trip statistics
- Mobile, tablet and desktop support

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub Pages
